# Калимба №12 — тюнер ре-мажор

Статическое веб-приложение с локальной обработкой микрофона. Раскладка: B5 F♯5 D5 A4 E4 B3 A3 D4 F♯4 B4 E5 A5, слева направо. A4 = 440 Гц, допуск ±5 центов.

## Запуск

`python3 -m http.server 8765 --directory docs`

Открыть http://localhost:8765. На телефоне нужен HTTPS, например GitHub Pages. Нажать «Начать настройку» и разрешить микрофон. Один щипок за раз; дать предыдущему звуку затихнуть. При сильной расстройке нажать на нужный язычок, чтобы зафиксировать цель.

## Проверки

`node tests/pitch.test.mjs` — 60 случаев высоты, все 12 нот с отклонениями, тишина.

`node tests/ui.test.mjs` — направление коррекции, устойчивое попадание, ручная фиксация, авто и устаревший сигнал.

MP3 пользователя проверен локально и не включён в опубликованные ресурсы. В нём звуки быстро накладываются; такие фрагменты могут намеренно не давать показаний. Нужна дополнительная проверка живой калимбы с микрофоном iPhone/Android. Браузерная проверка интерфейса не заменяет испытание реального микрофона.

## Реализация

Web Audio: два low-pass фильтра 1200 Гц, анализатор 8192 отсчёта, YIN-подобная оценка периода с интерполяцией, медианный фильтр и проверка устойчивости. Автовыбор допускается в пределах 48 центов от цели. При выборе вручную допустимо отклонение до 250 центов; более далёкий сигнал требует проверки номера.

При сворачивании захват прекращается. Аудио не записывается и не отправляется. Service worker кэширует только ресурсы интерфейса, не вход/переадресации. Установку и офлайн-поведение требуется проверить на конечных устройствах, включая запуск с домашнего экрана.

Визуальная схема основана на https://kalimba.fm/tune/. Это прототип, не утверждённый производителем официальный тюнер. Опорную частоту и инструкции по физическому перемещению язычков следует подтвердить у мастера перед массовым выпуском.

## Эталонный звук

Нажатие на язычок выбирает его и воспроизводит синтезированный затухающий тон с точной основной частотой по A4 = 440 Гц. Микрофон для этого не нужен. Повторное нажатие заменяет предыдущий звук. Измерение приостанавливается на 2 секунды (1,5 секунды звука плюс хвост) и возвращается к выбранному язычку. При сворачивании звук прекращается. Это ориентир по высоте, не воспроизведение тембра записанной калимбы.
